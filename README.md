# Samuel Ayomide Adeosun | Project Portfolio

This repository contains a curated portfolio of research-oriented projects and computational work in stochastic population genetics, mathematical biology, epidemiology, and related areas of applied probability.

My work focuses on mathematical modeling, stochastic processes, and simulation-based analysis of biological systems. This portfolio is intended to showcase my technical capabilities, research interests, and reproducible project work for academic and industry audiences.

## Overview

I am a biomathematician with an interest in:
- stochastic models in population genetics
- epidemiological modeling
- Markov processes and martingale problems
- fast–slow dynamics and complex biological systems
- computational methods and scientific programming in Python

## Featured Projects

- TE Abundance Simulation: stochastic and simulation-based modeling of transposable element abundance dynamics
- Markov Process Models: examples and implementations of Markov process concepts in applied settings
- Epidemic Dynamics: small-scale reproducible models for epidemic spread and dynamic systems

## Getting Started

Clone the repository:

```bash
git clone https://github.com/samueladeosun/samuel-portfolio.git
cd samuel-portfolio
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then explore individual project folders for run instructions and project-specific details.
